# Proyectos Web — Nivel Intermedio

Plan de 4 semanas, un proyecto por semana, con dificultad progresiva.

## [Semana 1](./semana%201) — To-Do List con persistencia

CRUD de tareas con persistencia en `localStorage` o una API simple (JSON Server).

**Objetivo:** reforzar manejo de estado, componentes y datos.

- Crear, editar, completar y eliminar tareas
- Persistencia de datos entre recargas
- Filtros (pendientes / completadas)

## [Semana 2](./semana%202) — Dashboard de clima o criptomonedas

Consumo de una API pública (fetch/axios) con visualización de datos.

**Objetivo:** practicar llamadas asíncronas, estados de carga y manejo de errores.

- Búsqueda por ciudad / moneda
- Loading states y manejo de errores
- Gráficas con Chart.js

## [Semana 3](./semana%203) — App de notas o blog con backend propio

Aplicación fullstack básica con backend propio en Node.

**Objetivo:** dar el salto a backend, base de datos y autenticación.

- Node + Express + BD (SQLite o MongoDB)
- Autenticación básica con JWT
- Rutas protegidas

## [Semana 4](./semana%204) — Clon de red social o e-commerce mini

Proyecto fullstack completo integrando todo lo anterior.

**Objetivo:** cerrar el mes con una app real, lista para producción.

- Login y sesiones
- Feed de posts o carrito de compras
- CRUD completo
- Deploy en Vercel / Render
